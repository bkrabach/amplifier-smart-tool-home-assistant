# Support

This is a community-maintained personal project. The maintainer responds on a
best-effort basis; paid support and an SLA are not available.

## Getting help

For usage questions, bugs, and feature requests, search existing issues and
documentation first, then open an issue in this repository:

https://github.com/bkrabach/amplifier-smart-tool-home-assistant/issues

Include the tool version, Linux distribution, Python version, and a minimal
sanitized reproduction where applicable. Do not share tokens, device inventory,
household data, or raw logs.

The project documents its Linux credential route in
`src/ha_analysis/SMART_TOOL.md` and the repository documentation. Other
operating systems are unsupported.

For a problem specific to Home Assistant or Amplifier rather than this tool,
their upstream documentation may help:

https://www.home-assistant.io/docs/

https://github.com/microsoft/amplifier-agent

## Security and conduct

For a security vulnerability, use the private reporting instructions in
`SECURITY.md`, not a public issue. For community expectations and conduct
concerns, see `CODE_OF_CONDUCT.md`.
